# Hi, I'm Raymond (aka theDivinePenguin)

Second-year AIML student at VBIT, Hyderabad. I mostly learn by building stuff I actually want to use, and I jump between tech stacks purely based on what looks fun lol.

When I'm not coding I'm usually playing video games, singing, or messing around on the piano.

---

### Stuff I've built

- **[cycml](https://github.com/theDivinePenguin/cycml)**: cyclone intensity forecasting and rapid intensification early warning (my SIH 2026 project). PyTorch, ResNet + temporal transformer.
- **[clashML](https://github.com/theDivinePenguin/clashML)**: learns the Clash Royale meta from 1.4M battles and suggests which cards to swap in your deck.
- **[urdev](https://github.com/theDivinePenguin/urdev)**: tracks how cities change over the years using satellite data from Google Earth Engine.
- **[rusma](https://github.com/theDivinePenguin/rusma)**: a lightweight CLI task manager / system monitor for Linux, written in Rust.
- **[blueprint-calculator](https://github.com/theDivinePenguin/blueprint-calculator)**: blueprint calculator for Asphalt Legends.
- **[coc-event-bot](https://github.com/theDivinePenguin/coc-event-bot)**: a Discord bot to manage Clash of Clans activities.
- **[Asphalt-bot](https://github.com/GTAVENOM/Asphalt-bot)** and **[Discord-Summary-Bot](https://github.com/GTAVENOM/Discord-Summary-Bot)**: Discord bots for Asphalt car info and for summarising conversations (built with a friend).

I also make Minecraft mods in Java every now and then.
